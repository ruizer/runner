# Daemon

Use the [procedure](../full-smoke-test.md) and an isolated development daemon containing exclusively ledger-listed test objects for any service-wide quit/crash/mismatch check. Preserve pre-existing sessions and the installed coordinator. Record app/daemon/child executable paths, PID plus creation time, keys, endpoint state, logs and elapsed shutdown/reconnect time. A stopped row or successful command alone is not proof that processes and descendants exited. Never manufacture a mismatch by editing source/binary bytes or perform a real logout/reboot as a substitute for a fixture.

Current authority: [process model](../../arch/process-model.md), [app lifecycle](../../../crates/runner-app/src/lifecycle.rs), [quit dialog](../../../crates/runner-app/src/surfaces/quit_dialog.rs), [managed connection](../../../crates/runner-core/src/protocol/managed.rs), [daemon boot](../../../crates/runner-daemon/src/daemon/boot.rs), [resume](../../../crates/runner-daemon/src/daemon/resume.rs) and [process launch](../../../crates/runner-core/src/daemon_process.rs). The cap is the third crash in five minutes, with two preceding automatic replacements; the old fourth-disconnect expectation is retired.
